## 修复答题进度不匹配 + 属性页黑色条 + 接入 GSAP 动效
用户用 @skill Gsap + Impeccable 反馈两个 bug 并要求继续改界面（不改题目）。

### Bug A：答题界面进度与题目数不匹配（TestPage.vue）
- 根因：`totalQuestions = questions.filter(q => !q.condition).length` 恒为 15，但 `getNextQuestion` 会按 q1 答案插入条件题 q1a/q1b（q1 多选可同时触发两者），真实路径为 15–17 题；`answers.length` 分子可能超过 15，NODE/进度分母失真。
- 修复：`totalQuestions` 改为按当前 `answers` **模拟真实路径长度**（从首个无条件下一题出发循环 getNextQuestion，visited 防环）。分子分母始终一致。
- AttributeTestPage 因属性题无 condition，原 `attributeQuestionOrder.length` 自洽，无需修。

### Bug B：属性分析页 ATTRIBUTE BREAKDOWN 黑色条（AttributeResultPage.vue）
- 根因：进度条轨道用 `bg-black/30`。
- 修复：改用设计系统 `.attr-bar`（oklch 冷蓝灰，非黑）+ `.attr-bar-fill`，保留内联按色渐变与辉光，高度用内联 16px 保持原观感。

### GSAP 动效接入
- 安装 `gsap`；新建 `src/utils/anim.ts`：`revealPage(getRoot, groups)` 封装 `gsap.matchMedia('(prefers-reduced-motion: no-preference)')` + `gsap.context` 时间线，组内 stagger、跨组 `>-0.35` 衔接，`clearProps:'opacity,transform'` 避免覆盖既有 class 动画，unmount `revert()`。
- 7 个页面：根 div 加 `ref="rootEl"`，元素加 `data-reveal` / `data-reveal-card` / `data-reveal-role` / `data-reveal-option` / `data-reveal-attr` 标签；onMounted 调 revealPage、onUnmounted revert。
- 把 ResultPage/AttributeResultPage/ProfilePage 原 `isAnimating` opacity-0 进入 hack 替换为 GSAP 揭示（消除"无 JS 时隐藏"风险，且 reduced-motion 用户直接显示）。TestPage/AttributeTestPage 保留各自 per-question 过渡（isTransitioning/q-fade），GSAP 仅做首屏入场（不作用带 class 切换透明度的面板自身）。
